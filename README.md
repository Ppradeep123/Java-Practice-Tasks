## ▶️ How to Run Java Programs

1. Clone this repository:

   ```bash
   git clone https://github.com/Ppradeep123/Java-Practice-Tasks.git
   ```

2. Open the project in VS Code or IntelliJ IDEA.

3. Navigate to any folder containing Java programs.

4. Compile the program:

   ```bash
   javac ProgramName.java
   ```

5. Run the program:

   ```bash
   java ProgramName
   ```
